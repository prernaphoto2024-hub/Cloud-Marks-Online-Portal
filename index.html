Online storage and faculty access

This preview works locally. For shared online storage, configure a Supabase project using the included supabase_schema.sql file, then enter your project URL and anon/public key below. Never put a service-role key in this page.

Connection settings are stored in this browser only. Create faculty accounts in Supabase Authentication and apply the database policies in the SQL file. The page requires an internet connection for Supabase mode.

Backup

Export a CSV backup regularly. Do not use local demo mode for official marks because data will not sync between devices.
